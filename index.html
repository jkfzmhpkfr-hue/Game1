غرفة الطاقة: موازنة المكثفات

اضبط قيم المحطات الكهربائية الثلاث بحيث يكون إجمالي الطاقة الإجمالية 100 Megawatts تماماً لفتح الباب الرئيسي.

إجمالي الطاقة الحالية: 80 MW
المكثف أ (التحكم بالشبكة) 20 MW
المكثف ب (تغذية الخوادم) 50 MW
المكثف ج (نظام التبريد) 10 MW

النواة الفائقة: التجاوز البرمجي الأخير

حل اللغز البرمجي التالي وأدخل النتيجة في موجه الأوامر (Terminal) لإلغاء القفل النهائي.

let result = "صوت";
if (word.returns && word.repeats) {
  result = "الصدى"; // echo
}
